# RailCrowd User Guide

This guide describes the intended user experience. Screens and workflows will become available as their implementation increments are merged.

## Finding a train

1. Open the RailCrowd homepage.
2. Search by train number, train name, or supported source/destination.
3. Select a matching train.
4. Review the train route and available coach information.
5. Check the crowd summary, report count and last-reported time.

## Understanding crowd status

Crowd status is generated from passenger-submitted observations. It is not an official passenger count and does not guarantee that space will be available.

- **Low:** recent reports indicate relatively less crowd.
- **Moderate:** recent reports indicate some crowd.
- **High:** recent reports indicate heavy crowd.
- **Very high:** recent reports indicate very heavy crowd.
- **No recent reports:** there is not enough fresh information to provide a useful summary.

Always check when the latest report was submitted and how many reports support the summary.

## Submitting a report

When signed in and travelling on the selected train:
1. Select the train.
2. Select the coach or coach category.
3. Select the current station or journey segment.
4. Choose the observed crowd level.
5. Add an optional factual note.
6. Submit the report.

Only submit observations you can reasonably verify. Do not submit reports for a train or coach you are not observing.

## Reporting abuse or incorrect information

Use the report flagging feature when a report appears misleading, duplicated or abusive. Do not publish another passenger's personal information or photograph without permission.

## Account safety

Use a unique password. Do not share login credentials. RailCrowd should never ask users to provide railway account passwords or payment details.
